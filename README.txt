ST. JOSEPH'S MINOR SEMINARY RESULT PORTAL
=============================================

This is a front-end prototype.

Student:
- Login with Student ID + Class + Password.
- View uploaded subjects, scores, grades and average.

Teacher/Admin:
- Click "Teacher / Admin Login".
- Demo teacher password: admin123
- Upload or update a student's result.

IMPORTANT:
This demo stores data in the browser's localStorage. It is NOT suitable for real school use yet.
For a real portal, we should add a secure backend/database, teacher authentication, password hashing,
student accounts, result sessions/terms, PDF result printing, and proper access control.
